# v1.0.2 — 摘要放到 30 字，语速降到约 1.5 倍

| 项 | 内容 |
|---|---|
| 发布日期 | 2026-11-06 |
| 版本类型 | 体验改进 |

| 是否需要重启 DSH | 否（移除旧版再装新版会热加载；个别环境没刷新时完全退出再启动一次） |

## 这一版做了什么

- 调整：摘要默认上限从 **20 字** 改成 **30 字**。
- 调整：默认语速从 `6`（约两倍）降到 `4`（实测约 **1.54 倍**），不再赶上「2 倍速」那样快。
- 改进：截断更聪明——优先停在句号/逗号等标点；英文句点只在后面是空格或结尾时才当句点，不会把「价格表.xlsx」从点处切断。
- 保持不变：提示音、自动选中文发音人、跳过子代理、合并连续回合、中断/报错不播。

## 使用方式

| 操作 | 怎么做 |
|---|---|
| 升级 | 重新安装 `conversation-voice-1.0.2.zip` 解压后的目录；装完直接生效 |
| 调字数 | 配置 `maxChars`（默认 30，最小 20） |
| 调语速 | 配置 `rate`：`0` 原速、`2` 约 1.25 倍、`4` 约 1.5 倍（默认）、`6` 约两倍、`10` 最快 |
| 回滚 | 重新安装 `releases/v1.0.1/` 或 `releases/v1.0.0/` |

无。插件不写文件、不改设置、不动会话数据。

## 已知限制

- 30 字仍是「开头一句」，长答复的细节听不到。
- 语速是近似值（`4` 实测 1.54 倍），觉得还快就调 `3` 或 `2`。
- 其余同 1.0.0：只支持 Windows、中文语音优先、无夜间静音。
