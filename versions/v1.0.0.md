## 这一版做了什么

- 新增：每一轮对话正常结束（`turn/end`）后，自动播放一声 Windows 系统提示音。
- 新增：提示音之后用 Windows 自带中文语音朗读这一轮**最终答复的摘要**（默认最多 120 字）。
- 新增：摘要自动清洗 Markdown（去掉代码块、表格线、标题/列表符号、表情），尽量切在句号处。
- 新增：子代理会话的回合不播报，避免一个任务响好几次。
- 新增：上一轮刚结束、下一轮马上开始时（目标模式自动续跑）取消上一轮的播报，延迟 0.9 秒合并。
- 新增：中断、报错、被拦截的回合不播报（只播正常完成和达到输出上限的回合）。
- 新增：播报串行排队，多个会话同时完成不会叠音，只保留最新一条待播摘要。
- 新增：12 个可选配置项（开关、提示音、语音、发音人、语速、音量、字数、前缀、延迟等）。

## 使用方式

| 操作 | 怎么做 |
|---|---|
| 安装 | 解压 zip，把 `conversation-voice/` 放到固定位置，让 Agent `install_bundle` 这个目录 |
| 正常使用 | 什么都不用做：每轮回答结束后自动「叮」一声 + 中文朗读摘要 |
| 换发音人 | 配置 `voice` 填发音人名称（README 有查名称的 PowerShell 命令） |
| 只要提示音 | 配置 `speech: false` |
| 只要语音 | 配置 `chime: false` |
| 关掉 | `enabled: false`，或直接卸载插件 |
| 卸载 | `plugin_manager` → `remove_bundle` |

## 数据结构变化

无。插件不写文件、不改设置、不动会话数据；只在内存里保存每轮最后的 assistant 文本用于生成摘要。

## 已知限制

- 只支持 Windows；依赖 Windows PowerShell 5.1 的 System.Speech 和系统声音。
- 自动模式优先选中文语音，系统没有中文语音时中文可能念不准。
- 摘要只念答复开头，长答复的细节听不到；`maxChars` 最大 500 字。
- 没有夜间静音、按会话过滤之类的策略；需要时下一版加。
- 播报依赖会话事件 `turn/end`；极少数情况下宿主日志写入失败导致事件缺失时不会播报。
